RadioTV 0.1 — User guide

RadioTV plays radio and audio from TV and sports streams in NVDA. The current interface is Vietnamese, with TV, Radio, Football and Favorites categories.

Using RadioTV

Search names or tags with or without Vietnamese accents. In TV, select a group and channel, then read the available schedule. Up/down browsing does not start playback. The favorites button toggles the station; favorites and volume persist across NVDA sessions.

Limitations and status

Version 0.1.0 is a candidate pending release review. Video, pause/resume, recording and automatic football-list updates are not implemented. The bundled catalog can become stale; 784 enabled entries are not a guarantee of working streams. Changing volume reopens the stream. EPG loads in the background and is refreshed after six hours on lookup. HTTP 200 alone is not treated as successful playback.
